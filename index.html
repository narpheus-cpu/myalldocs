    업로드 매뉴얼

    이 버튼은 언제 쓰나요?Google Drive에 원본 TXT/EPUB가 있고, 이제 시스템이 Gemini로 요약과 분석을 새로 만들게 하려는 경우에 사용합니다.

    한눈에 구분분석 결과가 아직 없다 → 도서 목록 JSONL분석 결과가 이미 완성됐다 → 완성 인덱싱 JSON

    업로드 전에 준비할 것

    1. Drive 원본을 확인합니다.서재지도에서 사용하는 [book] 폴더 아래에 해당 책의 TXT 또는 EPUB가 있어야 합니다. Google Docs는 지원하지 않습니다.
    2. 확장자가 .jsonl인 파일을 준비합니다.(서재지도 JSONL 생성기 이용)한 줄에 책 한 권을 적습니다. 여러 줄을 하나의 배열로 감싸거나 줄 끝에 쉼표를 붙이지 않습니다.
    3. 각 줄에 파일명과 식별용 발췌문을 넣습니다.Drive 파일 ID나 해시는 입력하지 않아도 됩니다. 발췌문은 원본을 찾고 작품을 식별하는 데만 사용됩니다.

    한 권을 적는 가장 간단한 예

    {"filename":"노인과 바다.txt","relative_path":"소설/외국","excerpt_start":"책 앞부분 일부","excerpt_middle":"책 중간 일부","excerpt_late":"책 뒷부분 일부"}

    실제 업로드 순서

    1. 매뉴얼 창을 닫고 ‘도서 목록 JSONL 업로드’를 누릅니다.처음이라면 Google 로그인 창이 먼저 열립니다.
    2. ‘Google 계정이 연결됐습니다’가 나오면 같은 버튼을 한 번 더 누릅니다.이번에는 파일 선택 창이 열립니다.
    3. 준비한 .jsonl 파일을 선택합니다.‘업로드 완료 · 원본 연결과 즉시 자동 처리를 요청했습니다’가 나올 때까지 이 페이지를 닫지 마세요.
    4. 인덱싱 대기열에서 진행 상태를 확인합니다.MATCHING은 원본 찾기, IDENTIFYING은 작품 식별, INDEXING은 분석 중, COMPLETE는 완료입니다.
    5. 완료 후 ‘전체 도서 목록’을 확인합니다.등록된 책을 열어 원문이 맞는지 확인하고, 틀렸다면 ‘원문 연결 수정’으로 바로잡을 수 있습니다.
    알아두세요
    • 업로드 등록이 끝난 뒤에는 페이지를 새로고침하거나 닫아도 백엔드 처리는 계속됩니다.
    • 같은 원문은 Drive 파일 ID와 내용 해시로 확인하여 중복 분석을 건너뜁니다.
    • PAUSED_RATE_LIMIT은 무료 Gemini 한도 대기 상태이며 저장된 지점부터 다시 이어집니다.
    문제가 생겼을 때
    • .jsonl 파일을 선택하세요 → 파일 이름 끝이 정확히 .jsonl인지 확인합니다.
    • NEEDS_METADATA_REVIEW → 작품을 안전하게 확정하지 못한 상태입니다. 대기열의 해당 항목을 확인합니다.
    • 즉시 실행 실패 → 아래 ‘GitHub 즉시 실행’에서 토큰을 검사·저장한 뒤 ‘대기열 지금 실행’을 누릅니다.

    이 버튼은 언제 쓰나요?다른 AI나 사람이 작품명·작가·요약·구간별 요약·추가 분석까지 이미 완성한 경우, Gemini를 다시 호출하지 않고 서재지도에 등록할 때 사용합니다.

    한눈에 구분분석 결과가 아직 없다 → 도서 목록 JSONL분석 결과가 이미 완성됐다 → 완성 인덱싱 JSON

    업로드 전에 준비할 것

    1. Drive 원본을 확인합니다.원문 보기를 사용하려면 [book] 폴더 아래에 대응하는 TXT 또는 EPUB가 있어야 합니다. 없어도 나중에 ‘원문 없음’을 선택할 수 있습니다.
    2. 확장자가 .json인 파일을 준비합니다.한 권짜리 JSON 객체, 여러 권을 담은 배열, 또는 한 줄에 한 객체인 JSONL 내용을 담을 수 있습니다. 파일 이름 끝은 반드시 .json이어야 합니다.
    3. 필수 항목이 모두 있는지 확인합니다.작품명, 작가명, 장르, 태그, 작품 유형, 핵심 요약, 상세 요약이 필수입니다.

    필수 구조의 간단한 모양

    {
  "identity": {
    "title": "작품명",
    "author": "작가명",
    "genre": "소설",
    "tags": ["태그1", "태그2"],
    "workProfile": {"primary": "fiction"}
  },
  "content": {
    "oneLineSummary": "핵심 요약",
    "overallSummary": "상세 요약",
    "sectionSummaries": [],
    "adaptiveAnalysis": []
  }
}

    실제 업로드 순서

    1. 매뉴얼 창을 닫고 ‘완성 인덱싱 JSON 업로드’를 누릅니다.처음이라면 Google 로그인 창이 먼저 열립니다.
    2. ‘Google 계정이 연결됐습니다’가 나오면 같은 버튼을 한 번 더 누릅니다.이번에는 파일 선택 창이 열립니다.
    3. 완성된 .json 파일을 선택합니다.‘업로드 완료 · 원본 연결과 즉시 자동 처리를 요청했습니다’가 나올 때까지 이 페이지를 닫지 마세요.
    4. 대기열에서 원본 연결과 등록 상태를 확인합니다.제목·작가·파일명·폴더명을 비교해 가장 가능성 높은 원문을 자동 연결합니다. 이 과정에서는 Gemini를 호출하지 않습니다.
    5. ‘전체 도서 목록’에서 결과를 확인합니다.잘못 연결된 원문은 도서 화면의 ‘원문 연결 수정’에서 바꿀 수 있고, 인덱싱 내용은 그대로 유지됩니다.

    books-json 폴더에서 자동으로 가져오기

    1. Google Drive의 books-json 폴더에 완성 JSON을 넣습니다.원본 파일은 이 폴더에 그대로 남고 이동되거나 삭제되지 않습니다.
    2. 매뉴얼을 닫고 ‘books-json 폴더 연결’을 누릅니다.해당 폴더를 한 번 선택하면 설정이 서버에 보존됩니다.
    3. 연결 뒤에는 기다리기만 하면 됩니다.페이지를 닫아도 약 20분마다 새 JSON을 확인해 순서대로 대기열에 넣습니다. 바로 확인하려면 ‘지금 확인’을 누릅니다.
    4. 이미 등록한 파일은 자동으로 건너뜁니다.같은 Drive 파일의 같은 버전과 내용이 같은 복사본은 다시 대기열에 넣지 않습니다.
    알아두세요
    • 자동 연결 후보가 여러 개여도 등록을 멈추지 않고 가장 가능성 높은 원문을 우선 연결합니다.
    • API 키·GitHub 토큰·원문 전체를 완성 JSON 안에 넣지 마세요.
    • 완성된 결과는 Google Drive가 아니라 GitHub의 도서 데이터에 저장되고 Pages 배포 후 목록에 나타납니다.
    문제가 생겼을 때
    • .json 파일을 선택하세요 → 파일 이름 끝이 정확히 .json인지 확인합니다.
    • JSON 문법 오류 → 따옴표·쉼표·중괄호가 맞는지 확인하고 다시 업로드합니다.
    • NEEDS_USER_REVIEW → Drive 원문을 확정하지 못한 상태입니다. 등록 후 ‘원문 연결 수정’으로 직접 선택할 수 있습니다.
    • RUN-FAILED 또는 즉시 실행 실패 → ‘GitHub 즉시 실행’의 토큰을 검사·저장하고 ‘대기열 지금 실행’을 누릅니다.
